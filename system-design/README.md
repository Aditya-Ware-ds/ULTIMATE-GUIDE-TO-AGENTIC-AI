# System design

Agent system-design case studies and interview prep, drawing on Module 12
(multi-agent), Module 16 (evaluation), Module 18 (security), Module 22
(long-horizon agents), and Module 24 (becoming a pro).

Each case study states a realistic prompt, walks through the trade-offs a senior
engineer would raise, and gives a reference architecture -- not a single "correct"
answer, since these problems don't have one. See
[Module 24, lesson 03](../curriculum/24-becoming-a-pro/lessons/03-system-design-interviews.md)
for how to use these and how to structure your own answer to a similar question.

- [`01-customer-support-agent-platform.md`](01-customer-support-agent-platform.md) -- a case where a single, well-tooled agent is the right call, not multi-agent.
- [`02-multi-agent-research-system.md`](02-multi-agent-research-system.md) -- a case where multi-agent genuinely earns its cost.
