# System design

Agent system-design case studies and interview prep, drawing on Module 12
(multi-agent), Module 16 (evaluation), Module 18 (security), Module 22
(long-horizon agents), and Module 24 (becoming a pro).

Structure once populated: each case study states a realistic prompt ("design a
customer-support agent for X constraints"), walks through the trade-offs a senior
engineer would raise, and gives a reference architecture -- not a single "correct"
answer, since these problems don't have one.
