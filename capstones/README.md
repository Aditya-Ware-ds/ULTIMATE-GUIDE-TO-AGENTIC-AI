# Capstones

Three large, end-to-end builds, done last, after Level 6. Each ships with a spec,
an architecture doc, an eval suite, a threat model, and a deploy guide -- the
artifacts a real team would expect around a production agent, not just the code.

1. **Production coding agent** -- fixes issues in a sample repo, scored on a
   held-out test set. Draws on Module 13 (coding agents) and Module 16 (evaluation).
2. **Multi-agent research system** -- with evals, tracing, and cost limits. Draws on
   Module 12 (multi-agent), Module 16 (evaluation), and Module 17 (observability).
3. **Secure enterprise agent** -- MCP tools, human approval gates, and a red-team
   report. Draws on Module 09 (HITL), Module 10 (MCP), and Module 18 (security).

See [PROGRESS.md](../PROGRESS.md) for build status -- these are built last, after
every level is complete.
