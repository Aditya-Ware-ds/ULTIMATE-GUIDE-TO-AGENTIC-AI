# Projects

Mid-size portfolio projects, meant to be done between curriculum levels once
you've finished the modules they depend on. Each project has its own `README.md`
with a spec and acceptance criteria, and reuses code from `shared/` and from the
curriculum labs that precede it -- these are integration exercises, not new
concepts.

Planned (see [PROGRESS.md](../PROGRESS.md) for build status):

| Project | After level | Depends on |
|---|---|---|
| Research assistant with citations | 1 | Modules 03-06 (tools, agent loop, context, RAG) |
| Customer-support agent with escalation | 2 | Modules 07-09 (memory, planning, HITL) |
| MCP server for a real public API | 3 (protocols) | Module 10 |
| Multi-agent content pipeline | 3 (multi-agent) | Module 12 |
| Data-analysis agent with a code sandbox | 4 | Module 13, `shared/sandbox/` |
