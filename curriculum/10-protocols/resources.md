# Module 10 resources

Verified 2026-09-22. The `mcp` package (2.2.0) claims in lessons 2 and the lab
were verified by installing the package and running the code directly, not
just reading documentation -- see this module's pitfalls.md for why that
mattered here.

- [Model Context Protocol -- specification (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28) -- the current spec this module targets.
- [MCP Python SDK -- GitHub](https://github.com/modelcontextprotocol/python-sdk) -- source for the `mcp` package used in this module's lab.
- [MCP Python SDK docs -- Get started](https://py.sdk.modelcontextprotocol.io/get-started/first-steps/) -- current server/client usage guide.
- [Agent2Agent (A2A) protocol -- official site](https://a2a-protocol.org/latest/specification/) -- the full task lifecycle, AgentCard, and message/artifact spec (this module's lab is a deliberate simplification, not the full spec/SDK).
- [Agent Skills -- open standard](https://agentskills.io) -- the `SKILL.md` format and progressive-disclosure model covered in lesson 3.
- [Claude Platform Docs: Agent Skills overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) -- Anthropic's own current documentation for the same standard.
