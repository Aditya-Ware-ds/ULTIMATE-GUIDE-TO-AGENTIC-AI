# Module 18 resources

Verified 2026-09-22.

- [OWASP Top 10 for LLM Applications (2025)](https://genai.owasp.org/llm-top-10/) -- the current, verified ranked list this module's lesson 03 table is built from (Prompt Injection #1, Excessive Agency #6).
- [OWASP: Agentic AI -- Threats and Mitigations](https://genai.owasp.org/resource/agentic-ai-threats-and-mitigations/) -- the OWASP Agentic Security Initiative's threat-model-based guide (first published 2025-02-17), confirmed separate from and complementary to the LLM Top 10.
- [OWASP GenAI Security Project](https://owasp.org/www-project-top-10-for-large-language-model-applications/) -- confirms the project's scope spans both LLM applications and agentic AI systems, and that there is no separate numbered "Top 10 for Agentic Applications" list as of this verification (a correction to an earlier, unverified assumption -- don't cite a specific "ASI01-ASI10" numbering without re-verifying it exists).
- [Simon Willison: Prompt injection explained](https://simonwillison.net/2023/Apr/14/worst-that-can-happen/) -- one of the earliest and clearest explanations of the direct-vs-indirect injection distinction and why it's structurally hard to solve with prompting alone.
