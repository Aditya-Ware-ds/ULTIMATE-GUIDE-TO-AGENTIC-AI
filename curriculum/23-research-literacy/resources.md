# Module 23 resources

Verified 2026-09-22.

- [DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models](https://arxiv.org/abs/2402.03300) -- this module's worked example (lesson 03); confirmed real via its arXiv abstract, and cross-checked against an independent implementation before its formula was used in Module 21.
- [Hugging Face TRL: GRPO Trainer](https://huggingface.co/docs/trl/main/en/grpo_trainer) -- the independent source used to cross-verify DeepSeekMath's GRPO formula, illustrating lesson 03's two-source verification approach.
- [Papers With Code](https://paperswithcode.com/) -- a practical tool for lesson 02's reproducibility check: cross-references papers against released code and reported benchmark leaderboards.
- [Andrej Karpathy: How I read a research paper](https://karpathy.github.io/2022/03/14/lecun1989/) -- an example of exactly the "attempt a small reproduction" discipline lesson 02 describes, applied to a classic paper (not agent-specific, but the reproduction methodology transfers directly).
