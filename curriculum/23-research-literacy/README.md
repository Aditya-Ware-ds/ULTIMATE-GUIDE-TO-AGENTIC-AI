# Module 23 -- Research literacy

**Difficulty:** ★★★★☆ · **Time estimate:** 3-4 hours

## Objectives

By the end of this module you can:

- Read an agent-research paper critically: separate the actual claimed contribution from incremental framing, and assess its evaluation methodology.
- Judge whether a paper's results are genuinely reproducible from what it actually publishes.
- Track the agent-AI frontier without falling for hype -- cross-checking claims the same way this curriculum's own ground rules require.

## Prerequisites

[Module 22 -- Long-horizon & autonomous agents](../22-long-horizon-and-autonomous-agents/README.md)

## Why this module exists

**This module has no code lab**, unlike every module before it -- research
literacy is a reading and judgment skill, not something a passing test
suite can verify. What it teaches is the exact discipline this entire
curriculum has practiced on itself: verify claims against primary sources,
date-stamp what you learn, and don't trust a plausible-sounding summary
over the actual source. Modules 14 and 18 both caught real, stale or
fabricated-sounding claims from this project's own original research plan
by applying exactly this discipline -- this module makes that process
explicit and teaches you to apply it yourself.
