# Module 11 resources

Verified 2026-09-22. Every framework's specific claims in this module's
lessons/labs were additionally verified by installing the package and
inspecting it directly -- see each lab's own "Last verified" line for the
exact version.

- [LangGraph documentation](https://langchain-ai.github.io/langgraph/) -- and specifically [`langchain.agents.create_agent`](https://reference.langchain.com/python/langchain/agents/) as the current (non-deprecated) agent factory.
- [OpenAI Agents SDK documentation](https://openai.github.io/openai-agents-python/) -- the `Agent`/`Runner`/`Model` architecture.
- [Claude Agent SDK -- Python reference](https://code.claude.com/docs/en/agent-sdk/python) -- and [PyPI: claude-agent-sdk](https://pypi.org/project/claude-agent-sdk/).
- [Agent Development Kit (ADK) documentation](https://google.github.io/adk-docs/) -- and the [`adk-python` GitHub repo](https://github.com/google/adk-python).
- [CrewAI documentation](https://docs.crewai.com/) -- the `Agent`/`Task`/`Crew` role-based model.
- [Microsoft Agent Framework -- GitHub](https://github.com/microsoft/agent-framework) -- including the 1.0 GA announcement merging AutoGen and Semantic Kernel.
- [Pydantic AI documentation](https://ai.pydantic.dev/) -- and specifically the [unit testing guide](https://ai.pydantic.dev/testing/) covering `TestModel`/`FunctionModel`.
- [smolagents -- GitHub](https://github.com/huggingface/smolagents) -- the `ToolCallingAgent`/`CodeAgent` distinction.
- [LlamaIndex Workflows / Agents documentation](https://developers.llamaindex.ai/python/framework/use_cases/agents/) -- and the [workflow testing guide](https://developers.llamaindex.ai/python/llamaagents/workflows/testing/).
