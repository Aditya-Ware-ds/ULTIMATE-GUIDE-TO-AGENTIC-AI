# Module 05 resources

Verified 2026-09-22.

- [Anthropic: Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) -- primary-source guidance behind this module's framing of context as a managed budget.
- [Lost in the Middle: How Language Models Use Long Contexts (Liu et al., 2023)](https://arxiv.org/abs/2307.03172) -- the original paper establishing the U-shaped positional-degradation effect referenced in lesson 03.
- [Chroma Research: Context Rot](https://research.trychroma.com/context-rot) -- the 18-frontier-model study referenced in lesson 03's discussion of length degradation, with real (not illustrative) measured figures -- read this for actual numbers; this module's `context_rot_demo.py` example uses made-up numbers for shape illustration only.
- [Claude Platform Docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows) -- current provider documentation on what counts toward a context window (also referenced in Module 01).
