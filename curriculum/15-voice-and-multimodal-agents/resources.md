# Module 15 resources

Verified 2026-09-22.

- [Anthropic: Vision](https://platform.claude.com/docs/en/build-with-claude/vision) -- the current image content block format, supported formats, request limits, and per-resolution token-cost table this module's lesson 01 and `AnthropicProvider` are built against.
- [OpenAI: Realtime API guide](https://developers.openai.com/api/docs/guides/realtime) -- the current transport (WebRTC/WebSocket), direct audio processing, and barge-in/turn-taking architecture this module's lesson 02 describes.
- [Google: Gemini Computer Use / multimodal docs](https://ai.google.dev/gemini-api/docs) -- Gemini's current multimodal input handling, for comparison against Anthropic's approach.
- [PNG file format specification (W3C)](https://www.w3.org/TR/png/) -- reference for this lab's hand-written minimal PNG encoder (used to generate a licensing-free test image without an external image library).
