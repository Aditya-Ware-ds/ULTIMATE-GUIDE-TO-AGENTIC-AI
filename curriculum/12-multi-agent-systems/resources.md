# Module 12 resources

Verified 2026-09-22.

- [Anthropic: How we built our multi-agent research system](https://www.anthropic.com/engineering/multi-agent-research-system) -- a real production write-up of an orchestrator-worker research system, including the failure modes (coordination overhead, duplicated work) this module's lesson 02 names.
- [Improving Factuality and Reasoning in Language Models through Multiagent Debate (Du et al., 2023)](https://arxiv.org/abs/2305.14325) -- the source paper behind lesson 01's debate topology.
- [AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation (Wu et al., 2023)](https://arxiv.org/abs/2308.08155) -- foundational multi-agent-conversation framework paper; AutoGen's ideas were merged into Microsoft Agent Framework, covered in Module 11.
- [OpenAI Agents SDK -- Handoffs](https://openai.github.io/openai-agents-python/handoffs/) -- the handoff topology (lesson 01) as a first-class framework feature, already used in Module 11's OpenAI Agents SDK lab.
- [Anthropic: Building effective agents](https://www.anthropic.com/research/building-effective-agents) -- orchestrator-workers, this module's structural precursor (Module 08, lesson 04).
