# Module 08 resources

Verified 2026-09-22.

- [Anthropic: Building effective agents](https://www.anthropic.com/research/building-effective-agents) -- primary source for the workflow patterns this module covers (prompt chaining/plan-and-execute, routing, parallelization, orchestrator-workers, evaluator-optimizer) and the workflow-vs-agent framing in lesson 05 (also referenced in Module 04).
- [Reflexion: Language Agents with Verbal Reinforcement Learning (Shinn et al., 2023)](https://arxiv.org/abs/2303.11366) -- foundational paper on the reflection/self-critique pattern behind lesson 02.
- [Python `asyncio.gather` -- official docs](https://docs.python.org/3/library/asyncio-task.html#asyncio.gather) -- the concurrency primitive used in lesson 03's parallelization pattern (also introduced in Module 00, lesson 04).
