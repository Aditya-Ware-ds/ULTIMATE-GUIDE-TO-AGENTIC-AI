# Module 24 -- Becoming a pro

**Difficulty:** ★★★☆☆ · **Time estimate:** 3-4 hours

## Objectives

By the end of this module you can:

- Turn this curriculum's own projects and capstones into a real, specific portfolio, not a vague "I studied agents" claim.
- Make a genuine first open-source contribution to an agent framework or tool.
- Work through an agent system-design interview question the way a senior engineer would: trade-offs first, not a single "correct" architecture.

## Prerequisites

[Module 23 -- Research literacy](../23-research-literacy/README.md)

## Why this module exists

**This module has no code lab**, like Module 23 -- it's portfolio and
career material, not something a test suite verifies. Level 6 closes here
because everything before it (the 24 modules, 5 projects, and the 3
capstones that follow this one) is the actual substance a portfolio needs;
this module is about presenting and applying that substance, not
generating new technical content. It's also where [`system-design/`](../../system-design/README.md)
gets its first real content -- worked case studies that draw on Modules
09, 12, 16, 18, 19, and 22 directly.
