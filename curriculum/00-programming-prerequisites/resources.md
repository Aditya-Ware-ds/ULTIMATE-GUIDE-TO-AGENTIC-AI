# Module 00 resources

Verified 2026-09-22. All links are to official documentation.

- [Python `dataclasses` -- official docs](https://docs.python.org/3/library/dataclasses.html) -- the full API this lesson's dataclass examples draw from.
- [Python `typing` -- official docs](https://docs.python.org/3/library/typing.html) -- type hint syntax reference.
- [Python `asyncio` -- official docs](https://docs.python.org/3/library/asyncio.html) -- the standard library module behind everything in `04-async-await.md`.
- [JSON -- official spec (json.org)](https://www.json.org/json-en.html) -- the entire format on one page.
- [Python `json` module -- official docs](https://docs.python.org/3/library/json.html) -- `dumps`/`loads` and error types.
- [MDN: HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) -- methods, status codes, headers, explained for a general audience.
- [httpx -- official docs](https://www.python-httpx.org/) -- the HTTP client used throughout this repo, sync and async.
- [uv -- official docs](https://docs.astral.sh/uv/) -- the package/environment manager this repo uses.
- [Git -- official documentation](https://git-scm.com/doc) -- the canonical reference; the `git status`/`add`/`commit`/`branch` commands in `05-git-and-environments.md` are the ones you'll use daily.
